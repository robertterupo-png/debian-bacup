My Coding & Systems Philosophy

Clarity is the highest virtue. I design simple, data‑driven systems that explain themselves, avoid unnecessary abstraction, and remain maintainable for years. Templates and automation ensure small adjustments deliver 100% accuracy.

Core Principles

  • Clarity First: Payroll logic and datasets should explain themselves without excessive comments or decoration.
  • Concise Naming: Short, meaningful identifiers like grossPay, taxRate, deductions, netPay.
  • Data‑Driven Design: Complexity belongs in data structures, not tangled conditionals.
  • Templates for Accuracy: Reusable templates keep results consistent and reduce human error.
  • Lean Philosophy: Inspired by suckless—simple, small, transparent systems; complexity is a liability.

Integrations

I design for clean API boundaries and seamless data flow with Pronto Xi, Able Payroll, MYOB, Westpac Handy Pay, Kundu Pay, Nasfund, NCSL, IRC, and other accounting, banking, superannuation, and compliance platforms.

Language Choices

  • Excel VBA: Macros to streamline repetitive payroll tasks and enforce consistent templates.
  • Python (Pandas): Vectorized dataset analysis, reconciliation, and reporting with clear audit trails.
  • JavaScript/HTML: Dashboards and web tools with data‑driven logic and clean separation of concerns.
  • C: Lean, performant components when directness and efficiency matter.
  • Erlang: Reliable, garbage‑collected concurrent processes for always‑on tasks.
  • Shell‑scripts: One‑liners for quick automation, data manipulation, and glue code across systems.

Design ethos: write code and systems that explain themselves; let data carry complexity; keep everything ruthlessly consistent.
